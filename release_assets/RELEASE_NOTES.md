# Ne:Extera v2.0.0 Release Notes

## 🎉 Ne:Extera v2.0.0 for exteraGram 12.10.1

### ✨ What's New
- 🎨 **New red logo design** with ghost privacy icon
- 🔄 **Auto-update system** for DEX (updates automatically without user prompt)
- 📝 **Updated credits** - removed @bleizix mentions
- 💬 **Custom preview messages** - Russian themed customization examples
- 🔧 **Windows build compatibility** fixed

### 🚀 Features
- 👻 **Ghost mode** - Hide online status, typing, read receipts
- 🕵️ **Spy mode** - Save deleted messages and TTL media
- 🎭 **TTL media preservation** - View-once content stays under spoiler
- 📝 **Message edit tracking**
- 🚫 **Shadowban** - Hide specific users
- 💎 **Local Premium** features
- 🔍 **Advanced filters** with regex support

### 📦 Installation

1. Install [exteraGram](https://github.com/exteraSquad/exteraGram) ≥ 12.8.1
2. Download `ne_extera_loader.plugin` from assets below
3. Place in `/sdcard/Android/data/top.qwq2333.exteraGram/files/ExteraConfigs/plugins/`
4. Restart exteraGram
5. The plugin will download and load the DEX automatically

- **classes.dex** (421KB) - Plugin DEX file for exteraGram
